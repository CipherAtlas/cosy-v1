⌘ SSave to a local layout file

P / B / Enter / EscDraw path / fence / finish / cancel

Drag on the map to make a path or fence; drag yellow points to reshape either. Choose an asset once to place several objects; Escape stops placement. Paint grass with Grass, or clear meadow grass and lane flowers with Erase. Each drag is undoable. Resident routes are edited in the inspector. Apply to local game updates the playable layout file; reload a local game preview to inspect it. Preserved presets remain read-only.
